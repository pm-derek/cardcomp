Live price store

Verified LP / MP / HP / DMG prices you click out to on desktop are saved to the live branch of pm-derek/cardcomp, so the phone sees them too. Needs a GitHub token with Contents: read and write on that one repo.

  1. github.com > Settings > Developer settings > Personal access tokens > Fine-grained > Generate
  2. Repository access: only pm-derek/cardcomp. Permissions: Contents, read and write. Expiry: 1 year.
  3. Paste it here.

Auto-recognition (experiment)

Reads the card on stream at each lot with Claude and fills CardComp's search. Switch it on and pick the model in the CardComp panel ("auto off" under the lot strip). Your key stays in this browser and is sent only to api.anthropic.com. Billing: your Console API credits.

CardSight, side by side

With a CardSight key (cardsight.ai, API Keys page), read-nows and lot-start reads also go to CardSight. Each read, a coin picks whose answer fills CardComp; the other is only recorded, so the log shows which is right more often. Calls are spread over the month so you never run out early. The key stays in this browser and is sent only to api.cardsight.ai.
