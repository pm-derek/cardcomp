Live price store

Verified LP / MP / HP / DMG prices you click out to on desktop are saved to the live branch of pm-derek/cardcomp, so the phone sees them too. Needs a GitHub token with Contents: read and write on that one repo.

  1. github.com > Settings > Developer settings > Personal access tokens > Fine-grained > Generate
  2. Repository access: only pm-derek/cardcomp. Permissions: Contents, read and write. Expiry: 1 year.
  3. Paste it here.

Your Whatnot username

So a lot you win is logged as yours. Exactly as it shows on stream, without the @.

Anthropic API key

Used for the thank-you replies on the Seller Portal Feedback tab (a draft per worded feedback, you press Send). The key stays in this browser and is sent only to api.anthropic.com. Billing: your Console API credits.

Return address

Used by the issue replies on a message thread when a buyer returns cards. Stays in this browser only.

Order history (repeat buyers)

Seller Portal > Orders > Export Orders gives a CSV of every order. Import it once and the Orders list, order pages, message threads and the thank-you inbox show "3 orders" beside buyers who have ordered before (hover: since when, total spent). Orders you open afterwards are added as you browse, so a re-import is only a tidy-up. Stays in this browser.

Customers page ↗ top buyers by lifetime spend, repeat rate, who went quiet, the feedback they left you.

Auto-recognition (experiment)

Reads the card on stream at each lot with Claude (the key above) and fills CardComp's search. Switch it on and pick the model in the CardComp panel ("auto off" under the lot strip).

CardSight, side by side

With a CardSight key (cardsight.ai, API Keys page), read-nows and lot-start reads also go to CardSight. Each read, a coin picks whose answer fills CardComp; the other is only recorded, so the log shows which is right more often. Calls are spread over the month so you never run out early. The key stays in this browser and is sent only to api.cardsight.ai.

Results, frames and costs: the recognition test page. Read now from the Whatnot tab: Ctrl+Shift+Y (Cmd+Shift+Y on a Mac) on a stream.
